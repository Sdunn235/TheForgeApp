Welcome to The Forge

This is the description for The Forge. Explain Use and design in a high top-down approach.

Character Design

This is where you will be able to do most things character related. Be it creating, editing, or viewing characters in the world. This will not only be players, but also NPCs, and other characters that may be in the world. This will be the main hub for character design and management.

  • Create/Edit
  • View Characters

Attributes Design

This is where the raw numbers behind every character are shaped. Strength, dexterity, constitution, intelligence, wisdom and charisma: what each one means, the range it can be rolled in, and how it feeds the vitals derived from it.

  • Create/Edit
  • View Attributes

Skill Design

This is where skills are defined and grouped into categories. Gathering, weapon handling, armor training and whatever else the world needs, each with its description and the range a character levels it through.

  • Create/Edit
  • View Skills

Ability Design

This is where abilities are written. These are what a character unlocks as a skill grows: what each one does, which skill category it belongs under, and what it takes to learn.

  • Create/Edit
  • View Abilities

Feat Design

This is where feats are written. These are the perks a character earns every few levels: what each one grants, whether it is earned or given as a bonus, and how many a character may hold.

  • Create/Edit
  • View Feats

Spell Design

This is where spells are written and sorted into schools. Abjuration through transmutation, each spell carrying its level, its mana cost, and what happens when it is cast.

  • Create/Edit
  • View Spells

Item Design

This is where gear and inventory are made. Weapons, armor, consumables and curiosities, each with the slot it fills, the quantity it stacks to, and what it does for whoever carries it.

  • Create/Edit
  • View Items
